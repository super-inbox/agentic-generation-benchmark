# Changelog

## 0.2.0 — 2026-10-29 — runnable toolkit

- Keep the v0.1 dataset, assets, historical scores and their checksums unchanged.
- List and validate all 83 public tasks: 43 design conditions and 40 RFQ scenarios.
- Add complete candidate input bundles with deliverables, constraints, reference roles and explicit unavailable prerequisites.
- Add a subprocess adapter, sequential design feedback, immutable output snapshots, and RFQ routing with fixed customer replies.
- Add configurable Gemini API evaluation, independent RFQ evidence annotation, actual visual attachments, per-requirement judgments and quality bounds with unknowns retained.
- Export new-run JSON/CSV summaries with execution and evaluation coverage, plus transport/prompt/model provenance.
- Add CLI preflight, a generic candidate CLI bridge, synthetic smoke agents, and API/runner/boundary regressions.
- This is a new portable protocol, not a reproduction of historical agent environments or a human-validated acceptance grader. No new empirical model scores or expert labels are introduced.

## 0.1.0 — 2026-10-26

- Present the existing repository as DRAFT-Bench while keeping its URL and the historical VIR image archive.
- Release 35 authored design briefs, 43 condition projections and 24 verified project-owned input assets.
- Release 40 RFQ scenarios and 100 archived dialogue/score records; preserve one infrastructure exclusion and 99 scored records.
- Provide the original RFQ v0.3 arithmetic and offline replay, plus candidate-input export and integrity checks.
- Publish 333 observation associations, 301 protocol units and 272 ID lineages as explicitly scoped numeric archive metadata.
- Include the separate seven-pair historical Sol/Astra R1 pilot with pending expert status.
- Add provenance, checksums, schemas, documentation, CI and code licensing. No new model calls or human labels.
